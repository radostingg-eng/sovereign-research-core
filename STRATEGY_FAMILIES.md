# Open Strategy Family Search Space v1

These are discovery anchors, not a closed whitelist. The agent may invent families outside them when the mechanism is plausible.

| Family | Typical mechanism | Preferred evidence |
|---|---|---|
| Deep value / FCF | price below normalized cash generation | statements, valuation history, filings |
| Quality at discount | temporary price compression without durable impairment | margins, ROIC/ROE, balance sheet, valuation |
| GARP | growth exceeds what valuation implies | growth, estimates, unit economics, valuation |
| Special situations | corporate action creates non-market supply/demand | filings, corp actions, IR releases |
| Event-driven | catalyst changes information or cash-flow path | primary event source, timeline, scenarios |
| Relative value | linked assets diverge beyond justified range | paired fundamentals + normalized spread |
| Volatility / options | implied/realized mismatch or skew/term structure edge | option chain, IV, realized vol, OI, liquidity |
| Hedging | reduce portfolio tail risk cheaply | correlation, beta, stress scenarios, hedge cost |
| Factor / macro | regime creates systematic mispricing or protection | macro series, factor exposure, regime history |
| Insider / ownership | informed ownership change is informative | Form 4/ownership filings, persistence |
| Institutional / 13F | capital allocation changes that persist | holdings and filing changes |
| Buybacks / capital return | shrinking share count or capital distribution changes value | filings, buyback authorization/execution |
| Restructuring / turnaround | self-help changes earnings power | debt, segments, guidance, operating metrics |
| Sentiment dislocation | crowding becomes mispriced relative to fundamentals | Stocktwits + independent fundamentals |
| Momentum / mean reversion | price behavior contains incremental information | clean historical data, regime controls |
| Source-disagreement | credible sources disagree in an exploitable way | timestamped multi-source observations |
| Instrument substitution | same thesis better expressed with another instrument | shares/options/spreads/ETF/hedge economics |

For every family, require a falsifiable mechanism, counter-hypothesis, portfolio-fit test and best counterfactual. A family is promoted only after evidence shows it adds decision value beyond the existing process.
